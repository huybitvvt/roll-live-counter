# Desktop interface decisions

The ui-ux-pro-max searches for industrial camera monitoring and manufacturing
dashboards returned landing-page patterns, which do not match a native desktop
operator tool. No verified native template was found. General desktop guidance
is used instead: high-contrast text, native keyboard-focus controls, visible
labels, no animation, count separated from unresolved identities, explicit stale
camera states and a dark video surface. Segoe UI is supplied by Windows; there
are no runtime font downloads.
